# Jujutsu Clash

Jogo de luta 2D de fã, inspirado no universo de Jujutsu Kaisen. Projeto independente, sem afiliação oficial.

## Como executar
1. Baixe ou clone o repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` com a extensão Live Server (ou abra o arquivo diretamente no navegador).
4. Clique em **Entrar na arena**, escolha um personagem e lute contra a CPU.

## Personagens
- Satoru Gojo
- Yuji Itadori
- Megumi Fushiguro
- Nobara Kugisaki
- Ryomen Sukuna
- Aoi Todo

## Controles
| Tecla | Ação |
|---|---|
| A / D | Andar |
| W | Pular |
| S | Defender |
| J | Ataque rápido |
| K | Ataque forte |
| L | Técnica especial |
| U | Técnica suprema (70 de energia) |
| Shift | Dash |
| Esc | Pausar |

Também existem botões de toque para movimentação e ataques em telas menores.

## Recursos
- Menu inicial e guia de controles.
- Seleção de seis personagens com atributos.
- Arena 2D com cenários variados.
- Combate contra CPU, vida, energia, cronômetro, defesa, dash, pulo e combos.
- Técnicas especiais e supremas com efeitos visuais.
- Arte procedural original desenhada no Canvas e CSS, sem reutilizar sprites de terceiros.

## Observações
Este é um protótipo jogável em evolução. Os personagens e referências pertencem aos respectivos titulares. As artes do protótipo são formas originais simplificadas, não sprites oficiais.
