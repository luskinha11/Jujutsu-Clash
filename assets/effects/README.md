# Efeitos animados opcionais

Coloque spritesheets horizontais PNG nesta pasta, com o nome igual ao tipo do efeito usado pelo jogo (ex.: `blue.png`, `red.png`, `purple.png`). Cada quadro deve ter 128×128 px por padrão. Para ajustar dimensões, quadros e FPS de um efeito, adicione sua configuração em `effects` no `assets/sprites/manifest.json`. Se não existir imagem, o efeito original desenhado pelo jogo continua funcionando.
